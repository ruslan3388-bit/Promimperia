# Экономика региона — версия 4.0

Биржа принимает заявки игроков на покупку и продажу, исполняет их по цене и времени, поддерживает частичные сделки. В резерв уходят деньги или товары. Срок заявки — 72 часа. Покупки и возвраты товаров ждут в пункте получения и не пропадают при полном складе. Комиссия продавца — 2%, для торговца — 1%. Лимит открытых заявок — 8, у торговца — 24.

Основная специализация даёт +25% выпуска своей отрасли. После выбора строить и изучать можно только свою ветку; общий рудник и электростанция остаются доступны всем. Остальные отрасли и исследования видны в компактных свёрнутых списках. Ранее построенные предприятия продолжают работать, а технологии и прогресс сохраняются при смене специализации. Первый выбор бесплатен; смена — 1 500 ₽ и не чаще раза в 24 часа. Доски нужны строительству; мука превращается в хлеб; ткань — в рабочую одежду. Снабжение рабочих хлебом даёт +10% выпуска; без хлеба сохраняется базовая скорость. На один работающий объект требуется 1 хлеб за 10 минут.

Лавка — резерв для одиночного региона. Её фиксированные котировки покупки/выкупа составляют 130%/60% справочной стоимости (торговая аналитика повышает выкуп до 63%); это ориентир баланса, не фактическая себестоимость конкретной компании. Покупка и выкуп ограничены отдельными часовыми квотами на каждый товар и компанию. Другой игрок не может исчерпать твой аварийный запас. Заявки игроков могут иметь любую целую цену от 1 до 1 000 000 ₽; цены НПС не ограничивают биржу.

Сервер подтверждает игровые команды после сохранения. Повторные requestId не исполняются повторно (последние 200 на компанию). Все команды проходят общую очередь одного процесса; нельзя запускать несколько серверов на одном JSON-файле. Для масштабирования на несколько процессов потребуется транзакционная БД. Ошибка записи переводит сервер в режим остановки действий с health 503. Состояние биржи, эскроу и история сохраняются вместе с игроками.

Проверки: npm test включает гонку двух покупателей через настоящие WebSocket, повтор команды, перезапуск, эскроу, квоты, специализации и хлеб. Браузерная проверка двумя изолированными сессиями выполнена отдельно на ширине 390 px.

# Promimperia

## Промышленники — Telegram Mini App 4.0

Экономическая стратегия: от первой шахты до орбитальной сети и города будущего. Одна кампания, семь отраслей, 27 предприятий, 25 ресурсов, 13 исследований и 11 целей с наградами. Игроки видят общий рынок, рейтинг и журнал региона.

## Развитие компании

- Добыча и металлургия: руда → сталь → специальные сплавы.
- Энергетика: базовые станции, угольные ТЭЦ и солнечные парки.
- Агропром: древесина, зерно и пищевые комбинаты.
- Нефтехимия: нефть → полимеры.
- Машиностроение: оборудование → роботы.
- Наука и космос: очки науки → технологии → спутники → орбитальная сеть.
- Строительство: карьеры добывают камень и песок; цементный и стекольный комбинаты снабжают завод стройматериалов. Жилые кварталы тратят энергию и создают стабильный денежный доход.

Стройка занимает время: три объекта в последовательной очереди. Исследования идут отдельно, по одному. Цена расширения растёт; часть строек требует материалов. Последнюю стройку или текущее исследование можно отменить с возвратом 80% затрат. Любую отрасль можно приостановить.

Каждое производство отдельно проверяет сырьё, энергию, свободное место и деньги на обслуживание. Дефицит одного завода не останавливает остальные. Склад начинается с 5 000 единиц каждого ресурса и расширяется. На бирже цену устанавливают игроки; в лавке действуют справочные котировки и часовые квоты. После сдачи контракта новый заказ готовится 90–300 секунд. Награды за цели выдаются один раз.

Кампания проходима в одиночку: текущая автоматическая стратегия через НПС завершает её за 850 минут моделируемого времени. Это не пользовательский плейтест и не обещание длительности; стратегия без специализации и торговли с людьми существенно медленнее прежней экономики. Офлайн-производство по-прежнему ограничено 8 часами.

## Прогресс и перенос

Состояние хранится в `data/world.json`: деньги, склад, предприятия, очереди, технологии, контракты, награды и события. Автосохранение — каждые пять секунд и после действий. Запись атомарная; `world.json.bak` содержит предыдущее сохранение. Повреждённый файл не перезаписывается: сервер откажется запускаться. Восстанавливать резервную копию следует только при остановленном сервере, предварительно сохранив повреждённый файл.

Офлайн-производство работает до восьми часов после последнего подключения. При запуске сервера пропущенный период рассчитывается с учётом сырья, расходов и склада. Таймеры стройки и исследований продолжаются по реальному времени. При аварийном завершении возможна потеря последних пяти секунд.

Старая кампания переносится без обнуления денег, построек и действующих контрактов. Новые технологии открываются с начала. Награды за уже достигнутые цели доступны в разделе «Цели и награды».

## Локальный запуск

Нужен Node.js 20+. Зависимости уже установлены; для нового окружения используйте `npm ci`.

```sh
npm start
```

Без `BOT_TOKEN` доступны локальные тестовые профили на `http://localhost:3000`. Они используют тот же файл данных по умолчанию; для отдельного теста задайте `GAME_DATA_FILE` на другой файл. Для локального тестирования ограничьте адрес через `GAME_HOST=127.0.0.1`.

Настройки окружения: `PORT`, `GAME_HOST`, `BOT_TOKEN`, `GAME_DATA_FILE`. При заданном токене доступны только Telegram-профили с проверенной подписью и свежим `initData`; локальный вход отключён. Токен никогда не передаётся клиенту.

## Игра у Петрушки

`scripts/start-petrushka.ps1` запускает скрытый процесс на `127.0.0.1:3001`, читает существующий токен из локальной конфигурации Hermes Desktop и пишет журнал в `data/server.log`. Не запускайте второй экземпляр на том же файле данных. Скрипт не запускает и не меняет Hermes.

Постоянная площадка — VDS `jolene`, публичный адрес `games.zernoai.ru`, путь игры `/promimperia/`. TLS уже настроен на обратном прокси. Игра работает отдельным Docker-контейнером, доступным на адресе внутренней сети `172.20.0.1:3138`; конфигурация Nginx находится в `deploy/nginx-games-location.conf`. Порт доступен обратному прокси на Docker-мосту. Маршрут `/` и остальные приложения на `games.zernoai.ru` остаются за прежним сервером. Обратный прокси передаёт WebSocket для игрового подключения.

На VDS секрет `BOT_TOKEN` хранится в локальном файле `.env` с закрытыми правами доступа. Сохранение кампании находится в Docker volume `data/world.json`. Обе вещи исключены из Git. Контейнер запускается автоматически после перезагрузки VDS. Обновление сервера: `git pull --ff-only` и `docker compose up -d --build`.

После обновления закройте Mini App полностью и снова откройте кнопкой «Играть», чтобы загрузились новые файлы.

## Работа с GitHub

Исходники проекта находятся в `ruslan3388-bit/Promimperia`. Сохранения игры, резервные копии, журналы, `.env` и `node_modules` исключены из репозитория. Не копируйте и не удаляйте `data/world.json` при обновлении кода.

## Проверки

```sh
npm test
npm run simulate
```

Тесты проверяют экономические ограничения, очереди, награды, миграцию, сохранение, подпись Telegram, WebSocket и восстановление сервера. Интеграционные тесты запускаются с фиктивным токеном и временной базой, отдельно от живой игры.

`GET /health` показывает версию, число подключённых игроков и состояние записи на диск. Исходный код прежней версии лежит в `backups/before-expansion-20261108-152437/`; снимок перед переносом — `backups/live-before-v3-final.json`.
